📋 Instruções de Uso

  1. Para documentos HTML: Inclua o arquivo CSS e use as classes apropriadas
  2. Para documentos PDF: Use o arquivo SVG como imagem de fundo
  3. Para apresentações: Importe o SVG ou use as classes CSS
  4. Para impressão: As marcas d'água ficam automaticamente mais sutis
  5. Para responsividade: As marcas se ajustam automaticamente a diferentes tamanhos de tela

Classes CSS Principais:

  • .marca-iara-agua - Marca d'água padrão (30% opacidade)
  • .marca-iara-agua-sutil - Marca d'água sutil (15% opacidade)
  • .marca-iara-agua-gradiente - Marca d'água com gradiente
  • .marca-iara-agua-center - Centralizada
  • .marca-iara-agua-top-left - Canto superior esquerdo
  • .marca-iara-agua-top-right - Canto superior direito
  • .marca-iara-agua-bottom-left - Canto inferior esquerdo
  • .marca-iara-agua-bottom-right - Canto inferior direito
