Como Usar Sua Marca d'Água

Escolha o estilo que mais combina com seus projetos e baixe o arquivo SVG correspondente.

  • Para documentos: Insira a imagem SVG com transparência reduzida
  • Para imagens: Use programas como Photoshop, GIMP ou Canva para adicionar a marca d'água
  • Para vídeos: Importe o SVG em seu editor de vídeo e ajuste a opacidade
  • Para web: Use o código SVG diretamente no HTML ou CSS

Dica: Os arquivos SVG são vetoriais, então podem ser redimensionados sem perder qualidade!
