# 🎨 Marca Gráfica - Iara Carreira

Uma identidade visual completa e profissional criada especificamente para Iara Carreira, com múltiplas variações para diferentes usos e projetos.

## 📁 Arquivos Incluídos

- **`marca-iara.html`** - Visualização completa de todas as variações da marca
- **`marca-iara.css`** - Arquivo CSS com todas as classes da marca
- **`marca-iara.svg`** - Marca principal em formato vetorial SVG
- **`marca-agua-iara.svg`** - Marca d'água específica para projetos
- **`exemplo-uso.html`** - Demonstrações práticas de uso
- **`README.md`** - Este arquivo de instruções

## 🚀 Como Usar

### 1. Visualizar a Marca
Abra o arquivo `marca-iara.html` no seu navegador para ver todas as variações disponíveis.

### 2. Usar em Projetos HTML
```html
<!-- Incluir o CSS -->
<link rel="stylesheet" href="marca-iara.css">

<!-- Marca d'água centralizada -->
<div class="marca-iara-agua marca-iara-agua-center">IARA CARREIRA</div>

<!-- Marca d'água no canto superior direito -->
<div class="marca-iara-agua marca-iara-agua-top-right">IARA CARREIRA</div>

<!-- Marca d'água sutil no canto inferior esquerdo -->
<div class="marca-iara-agua-sutil marca-iara-agua-bottom-left">IARA CARREIRA</div>
```

### 3. Usar em Documentos PDF
- Importe o arquivo `marca-agua-iara.svg` como imagem de fundo
- Ajuste a opacidade conforme necessário
- Posicione no local desejado

### 4. Usar em Apresentações
- PowerPoint: Importe o SVG como imagem
- Google Slides: Faça upload do SVG
- Keynote: Arraste o arquivo SVG para o slide

## 🎯 Variações Disponíveis

### Marcas Principais
- **`.marca-iara-principal`** - Para títulos e cabeçalhos
- **`.marca-iara-simples`** - Para uso geral
- **`.marca-iara-minimalista`** - Para espaços pequenos
- **`.marca-iara-destaque`** - Com gradiente colorido

### Marcas D'água
- **`.marca-iara-agua`** - Padrão (30% opacidade)
- **`.marca-iara-agua-sutil`** - Sutil (15% opacidade)
- **`.marca-iara-agua-gradiente`** - Com gradiente sutil

### Posicionamento
- **`.marca-iara-agua-center`** - Centralizada
- **`.marca-iara-agua-top-left`** - Canto superior esquerdo
- **`.marca-iara-agua-top-right`** - Canto superior direito
- **`.marca-iara-agua-bottom-left`** - Canto inferior esquerdo
- **`.marca-iara-agua-bottom-right`** - Canto inferior direito

### Formas Especiais
- **`.marca-iara-circulo`** - Marca circular
- **`.marca-iara-quadrado`** - Marca quadrada
- **`.marca-iara-vertical`** - Marca vertical

## 🎨 Paleta de Cores

- **Primária:** `#667eea` (Azul)
- **Secundária:** `#764ba2` (Roxo)
- **Texto:** `#333333` (Cinza escuro)
- **Texto Claro:** `#666666` (Cinza médio)
- **Texto Mais Claro:** `#999999` (Cinza claro)

## 📱 Responsividade

A marca se adapta automaticamente a diferentes tamanhos de tela:
- **Desktop:** Tamanhos originais
- **Tablet (≤768px):** Redução de 20-30%
- **Mobile (≤480px):** Redução de 40-50%

## 🖨️ Impressão

Para impressão, as marcas d'água ficam automaticamente mais sutis (10% opacidade) para não interferir na legibilidade.

## 🔧 Personalização

### Alterar Cores
Modifique as variáveis CSS no arquivo `marca-iara.css`:
```css
:root {
  --marca-primary: #sua-cor-azul;
  --marca-secondary: #sua-cor-roxa;
}
```

### Alterar Tamanhos
Ajuste os valores de `font-size` nas classes desejadas.

### Alterar Opacidade
Modifique os valores de `opacity` nas classes de marca d'água.

## 💡 Dicas de Uso

1. **Documentos Formais:** Use `.marca-iara-agua-sutil` para não interferir na leitura
2. **Apresentações:** Use `.marca-iara-destaque` para chamar atenção
3. **Logos:** Use `.marca-iara-circulo` ou `.marca-iara-quadrado`
4. **Layouts Verticais:** Use `.marca-iara-vertical`
5. **Marca D'água:** Use `.marca-iara-agua` com posicionamento desejado
