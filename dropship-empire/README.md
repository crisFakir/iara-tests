## 🎯 CONFIGURAÇÃO RÁPIDA (5 MINUTOS)

### 1. Instalar Dependências
```bash
cd dropship-empire
npm install
```

### 2. Configurar Stripe (Pagamentos)
1. Criar conta em [stripe.com](https://stripe.com)
2. Copiar as chaves da Dashboard
3. Editar `.env.local`:
```env
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_sua_chave_aqui
STRIPE_SECRET_KEY=sk_test_sua_chave_aqui
```

### 3. Iniciar a Loja
```bash
npm run dev
```

Acesse: http://localhost:3000

## 🌐 DEPLOYMENT (GRÁTIS)
